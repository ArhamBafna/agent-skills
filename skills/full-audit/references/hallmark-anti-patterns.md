# Hallmark anti-patterns

This is the canonical named-tell list for the anti-AI visual audit.

## Critical tells

- Purple-to-blue or purple-to-pink gradient hero patterns
- Generic one-font UI with the same face used for display and body
- Equal-column feature grids that read as the default LLM layout
- Nested card systems with card-inside-card composition
- Gradient text and other decorative fill tricks that mimic AI design
- Thick stripe accents used like a fake UI hierarchy
- Full-viewport centered hero that collapses the page into a generic template
- Pure-black or pure-white base surfaces without tonal adjustment
- Default SaaS nav/footer chrome without real product logic
- Ambient blob or orb decoration used as filler instead of content
- Sound-on autoplay in hero media
- Fake proof bars or unverified metrics presented as facts

## Major tells

- Motion that reads as artificial bounce or elastic recoil
- Centered layouts repeated without a structural point of view
- Italic headings that feel like a generic editorial trick
- Repetitive section labels that do not carry real meaning
- Dark-surface glow or shadow effects that look synthetic
- Generic icon-tile blocks repeating the same shape
- Glassmorphism used as decoration instead of depth
- Hover-only affordances that hide information from touch users
- Excessive scroll-based motion that never settles
- Mixed icon styles that make the system feel unowned
- Illustration treatments that look like stock AI filler
- Emoji used as a substitute for a real design system
- Fake chrome or redrawn UI frames that already exist in the environment

These are the anti-AI visual signatures the audit should flag when they appear.
