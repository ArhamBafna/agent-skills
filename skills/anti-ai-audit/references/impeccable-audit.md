# Impeccable audit cues

This file supplies the design-critique layer of the audit: whether the interface feels authored for the actual product or reads as interchangeable template work.

## Core lens

The key question is not whether the layout is pretty. It is whether the composition and structure are specific, coherent, and grounded in real goals and audience needs.

## Assessment dimensions

The critique should weigh:
- design specificity
- hierarchy and information flow
- cognitive load
- emotional fit and product voice
- accessibility and interaction quality
- implementation integrity versus generic drift

## What to look for

A strong anti-AI pass should flag pages that seem category-interchangeable, structurally repetitive, or lacking a real product point of view. The tool should prefer concrete judgment over generic taste comments.

## Summary

This file is the “is it actually designed for this product?” check in the anti-AI audit, and it complements the visual slop list with a judgment about coherence and specificity.
