# Hallmark slop test

This file is the gate-based audit layer: it turns anti-AI detection into a checklist of concrete failure conditions before anything is shipped.

## The review structure

Before a verdict is given, the output should be checked for philosophy, hierarchy, execution quality, specificity, restraint, and variety.

## What the gates cover

The Hallmark gate set checks at least five categories:
- visual defaulting
- structural sameness and template repetition
- motion and interaction noise
- contrast and readability failures
- responsiveness and layout safety
- copy honesty and proof integrity

## What qualifies as a failure

A page fails the slop test when it reads as a generic template, repeats the same macrostructure, relies on low-effort default aesthetics, or inserts proof claims without real source material.

## Use in anti-AI audit

This file should be treated as the enforcement pass: it is where a visually plausible page is checked against the real reliability thresholds that separate generated-work-from-template from intentional design.
