# Motion Design Studio

Generate professional, high-converting product launch videos, UI morph loops, and kinetic typography rendered directly from code.

Videos in this pipeline are not generated by black-box video models. They are deterministic web programs (`index.html`) evaluated frame-by-frame via headless browser (`scripts/render.js`) and stitched with FFmpeg.

---

## Non-Negotiable Core Rules (Anti-AI Slop)

1. **NEVER use asynchronous timers**: Do NOT use `setTimeout`, `setInterval`, or wall-clock `Date.now()`. Browser performance fluctuates during headless recording; timers cause frame drops and desync. All visual state must be a pure, deterministic mathematical function of time: `window.seek(t)`.
2. **NEVER use standard CSS easing curves for mass**: Basic bezier curves feel cheap and robotic. Always use closed-form springs (`references/motion.js`) so motion has physical mass, momentum, and subtle overshoot.
3. **NEVER crop 16:9 to make 9:16 vertical**: Different aspect ratios require distinct layouts. Type, cards, and UI must re-align responsively to canvas width and height.
4. **NEVER present video without inspecting stills**: Before completing the task, always inspect rendered keyframe images. Fix visual collisions, clipped text, or empty canvas states.
5. **NEVER introduce non-deterministic randomness**: If randomness or noise is used, seed it deterministically. Every frame at time $t$ must render identically every run.
6. **NEVER default to generic AI-slop aesthetic**: Avoid "brief contagion" (identical dark purple gradient soup with floating cards). Commit to an intentional visual direction matching the project: Brutalist/Technical, High-Craft Editorial, Kinetic Typography, or Playful/Warm.

### Phase 1: Pre-flight Tool Verification

Verify system dependencies before proceeding:
1. Check `node -v`
2. Check `ffmpeg -version`
3. Check `npx playwright --version`

**If any tool is missing**:
- Present exact installation commands to user:
  - Windows: `winget install Gyan.FFmpeg` / `winget install OpenJS.NodeJS`
  - macOS: `brew install ffmpeg node`
  - Linux: `sudo apt-get install ffmpeg nodejs npm`
- Ask user: "Tool X is missing. Would you like me to install it, or will you install it manually?" Wait for confirmation.

**Completion Criterion**: `node`, `ffmpeg`, and `npx playwright` execute successfully.

### Phase 2: Codebase Scan & User Confirmation

Do NOT ask the user for information already present in the workspace.
1. Scan project root: inspect `package.json`, `README.md`, brand assets, logos (`public/`, `assets/`, `images/`), and CSS color tokens.
2. Extract:
   - Project / Brand Name
   - Core value proposition or hero headline
   - Brand color palette (Primary, Accent, Background)
   - Available image/SVG assets
3. **Confirm with user**:
   Present your findings concisely:
   > "I scanned your project and found:
   > - Name: [Brand]
   > - Headline: [Tagline]
   > - Colors: [Hex codes]
   > - Assets: [List of logo/image paths]
   >
   > Does this look correct, or would you like to make any adjustments?"

**Completion Criterion**: User approves or corrects the scanned brand profile.

### Phase 3: Intake Interview for Missing Specifics

Ask the user targeted questions to lock down the production spec:

1. **Target Folder**: Ask where to generate files (recommend `./motion/`).
2. **Animation Style**:
   - *Product Launch Reel*: UI screenshots, feature highlights, kinetic headline, CTA.
   - *UI Morph Loop*: One central shape or card morphing continuously through app states.
   - *Kinetic Typography*: Dynamic text transitions, bold contrast, fast-paced rhythm.
3. **Aspect Ratio**:
   - `16:9` (1920x1080) for YouTube / Web Hero
   - `9:16` (1080x1920) for TikTok / Instagram Reels / Shorts
   - `1:1` (1080x1080) for LinkedIn / X (Twitter)
   - `All three` (renders multi-format from responsive layout)
4. **Duration**: Default is 15 seconds (ideal for 6-8 fast-paced shots). Custom: 5s to 60s.
5. **Audio**:
   - Ask: "Do you want audio in the video?"
   - If **Yes**: Ask user to provide file path to an audio track (`.mp3` or `.wav`).
   - If **No**: Proceed without audio.

**Completion Criterion**: All 5 parameters are explicitly settled.

### Phase 4: Setup & Staging

1. Create target project folder (e.g. `./motion/`).
2. **Copy bundled tools**:
   - Locate the installed skill directory path for `motion-design`.
   - Copy `scripts/render.js` into `<target-folder>/render.js`.
   - Copy `references/motion.js` into `<target-folder>/motion.js`.
3. If user provided an audio file, verify path and ensure accessible in project folder.
4. **Selective Reference Loading**:
   - **For Product Launch Reels, UI Morphs, or Kinetic Typography**: Read [`references/spec-template.md`](references/spec-template.md) to draft a custom `SPEC.md`. **Do NOT load** `references/director-brief-template.md`.
   - **For Multi-scene Narrative Films or Story-Driven Animations**: Read [`references/director-brief-template.md`](references/director-brief-template.md) to draft the creative brief. **Do NOT load** `references/spec-template.md`.

**Completion Criterion**: Target directory contains `render.js`, `motion.js`, and staged brand assets.

#### Motion Design Guidelines
- **Use Springs for Real Mass**:
  - `snappy` (`stiffness: 350, damping: 26`): Buttons, badges, toggles.
  - `default` (`stiffness: 180, damping: 20`): Modals, cards, layout expansion.
  - `heavy` (`stiffness: 120, damping: 18, mass: 2`): Large hero headlines, brand logos.
  - `playful` (`stiffness: 220, damping: 14`): Icons and celebratory tags with overshoot.
- **Continuous Multi-Target Motion**:
  When an element transitions between multiple positions, use `Motion.track(t, keyframes)` rather than resetting animations.
- **Pacing**: Introduce a new visual moment or motion shift every 2 to 3 seconds.

**Completion Criterion**: `index.html` opens cleanly in browser and `window.seek(t)` executes without errors for any $t \in [0, \text{duration}]$.

### Phase 6: Frame Rendering & Stitching

Execute the render script via Node.js from the project folder:

```powershell
node render.js --input index.html --output output.mp4 --fps 60 --duration 15 --width 1920 --height 1080
```

*If audio was provided*:
```powershell
node render.js --input index.html --output output.mp4 --fps 60 --duration 15 --width 1920 --height 1080 --audio music.mp3
```

*For vertical 9:16*:
```powershell
node render.js --input index.html --output output_vertical.mp4 --fps 60 --duration 15 --width 1080 --height 1920
```

The script automatically:
1. Opens headless browser and verifies `window.seek`.
2. Captures all $N$ frames at 60 fps into a temporary directory.
3. Automatically saves 6 keyframe still images to `./stills/` for critique.
4. Encodes and stitches frames into an MP4 video using FFmpeg.

**Completion Criterion**: `output.mp4` and keyframe still images in `./stills/` exist on disk.

---

### Phase 7: Two-Stage Critique & Quality Gate

Never hand over a video without verifying frame quality.

#### Stage 7A: Autonomous Visual Critique
1. Use file viewing / image inspection tools to examine the extracted images in `./stills/`:
   - `keyframe_*.png`
2. Evaluate against the 5 quality pillars:
   - **No text clipping or boundary overlap**: Text must not touch canvas borders.
   - **Contrast**: Text and key UI elements must stand out clearly from backgrounds.
   - **Alignment & Polish**: Visual elements must be centered or intentionally anchored.
   - **No empty/broken frames**: Ensure SVG icons, images, and fonts loaded properly.
3. If flaws are found:
   - Modify `index.html` to correct coordinates, padding, or spring timings.
   - Re-run `node render.js`.
   - Repeat until score reaches >= 8/10.

#### Stage 7B: Human Review
1. Provide the user with:
   - The absolute file path to the final `output.mp4`.
   - Paths to keyframe screenshots in `./stills/`.
   - A brief summary of the scenes and visual timing.
2. Ask the user if any styling, pacing, or copy changes are desired.

**Completion Criterion**: Autonomous critique passes and user reviews final video output.

## Troubleshooting & Edge Cases

| Issue | Root Cause | Solution |
| :--- | :--- | :--- |
| `window.seek is not defined` | Script error or timing bug in `index.html` | Open `index.html` in browser console, check for JS syntax errors. |
| Playwright missing | Package not installed in local environment | Run `npm install -D playwright` in the project directory. |
| Stuttering motion in MP4 | `Date.now()` or linear interpolation used | Replace with `Motion.track(t, keyframes)` using closed-form springs. |
| Text cut off on vertical render | Fixed pixel widths used in CSS | Use responsive units (`vw`, `%`, `clamp()`) or calculate positions dynamically in `seek(t)`. |
| FFmpeg command error | Missing codecs or invalid frame sequence | Ensure `ffmpeg` is in system PATH and input pattern matches `frame_%06d.png`. |
